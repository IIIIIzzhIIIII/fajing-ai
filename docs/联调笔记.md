# 联调笔记 · 发镜 AI

> 记录每个页面对接的接口、降级策略与已验收结论。后端默认 `http://localhost:8080`（前端 `src/api/request.js` 内 `BASE_URL`）。

## 全局约定

- 统一返回体：`{ code, msg, data }`，`code !== 0` 由 `request.js` 统一 toast，页面只 `catch` 不再重复提示。
- 本阶段 `userId = 1` 写死在后端 `QuotaService.USER_ID` / `GenerationService.USER_ID`，后续换 JWT。
- 列表类接口都做了 mock 兜底：后端未启动时页面不白屏。

## 页面 × 接口

| 页面 | 接口 | 说明 / 降级 |
| --- | --- | --- |
| 首页 | 无（读本地 store） | 额度来自 Pinia，进页面时本地恢复 |
| 上传 | `POST /api/upload` | 失败时保留本地临时路径继续流程；校验 jpg/png/webp 且 ≤10MB |
| 选发型 | `GET /api/hairstyles`、`GET /api/colors` | 失败回退 `src/mock/constants.js`；`img` 为空时用 `PORTRAIT(en, gender)` |
| 生成中 | `POST /api/generate`、`GET /api/generate/{taskId}` | 1s 轮询；已有 taskId 时继续轮询不重复提交；失败可重试 |
| 结果 | `GET /api/unlocks`、`GET /api/generate/{taskId}` | `onShow` 同步解锁状态；无 result 时按 taskId 拉取，仍空则回首页 |
| 沟通卡 | 无（读 `app.result`） | 规格优先 `BARBER_SPEC[gender][cat]`，缺失用 `BARBER_FALLBACK` |
| 我的 | `GET /api/records`、`GET /api/quota` | 接口失败回退本地 `history` |
| 讨论 | `GET /api/posts`、`POST /api/posts/{id}/like`、评论接口 | 失败回退 `COMM_POSTS`；点赞乐观更新，失败回滚 |
| 弹层（全局） | `POST /api/order/mock`、`POST /api/share/reward`、`GET /api/unlocks` | 支付成功写入解锁；分享奖励每日/终身标记同步 UI |
| 管理后台 | 全部 `/api/admin/**` | header `X-Admin-Token: admin-token`，无 token 返回 `code=1` |

## 已完成的接口冒烟结论

在 `8090` 端口临时启动后端（8080 被本机 `xml.exe` 占用）完成验证：

- `GET /api/hairstyles` → 20 条（女 12 / 男 8），`img` 自动生成
- `GET /api/colors` → 8 条
- `POST /api/generate` → `taskId=1`；10s 后 `status=success`、`progress=100`、4 款结果
- `GET /api/records` → 1 条；`GET /api/unlocks` → `["f1"]`（首款默认解锁）
- `GET /api/posts` → 5 条，tags/评论正确返回
- `POST /api/posts/1/like` → `{liked:true, likes:129}`
- `POST /api/posts/1/comments` → 新增成功
- `POST /api/order/mock` → `{paid:true, amount:12, styleIds:[f1..f4]}`
- `POST /api/share/reward` → 首次成功，第二次返回「分享奖励已领取（每账号限 1 次）」
- `/api/admin/**` 无 token 返回「无管理端访问权限」，带 token 正常

## 已知限制

1. 本机 8080 被 `xml.exe` 占用，全栈联调需先释放端口或把 `BASE_URL` 改成 8090。
2. 生成结果图为 picsum 占位图，接入真实 AI 后替换 `GenerationService.placeholder()`。
3. 微信小程序端保存图片暂不做 Canvas 水印合成。
4. GitHub 推送当前网络无法直连 `github.com:443`，需配置代理后 `git push`。
